# Entorno de laboratorio

## Objetivo

Preparar un entorno virtual controlado para realizar una demostración educativa relacionada con el phishing y la ingeniería social, permitiendo ilustrar el funcionamiento de este tipo de amenazas y sus riesgos.

## Entorno utilizado

Para el desarrollo de la demostración práctica se utilizaron las siguientes herramientas:

- VirtualBox: software de virtualización utilizado para ejecutar el entorno de laboratorio.
- Kali Linux: distribución Linux utilizada como entorno de trabajo para la demostración.
- Zphisher: herramienta utilizada en la actividad demostrativa relacionada con el phishing.

## Virtualización

El entorno de práctica se ejecutó mediante VirtualBox, lo que permitió trabajar con una máquina virtual aislada del entorno principal de trabajo.

La virtualización facilitó la preparación y ejecución de la demostración con fines educativos, evitando la intervención sobre sistemas reales de la institución.

## Demostración

La actividad consistió en una demostración controlada para explicar cómo funcionan determinadas técnicas de phishing, cómo se presentan los engaños y qué riesgos pueden representar para los usuarios.

El propósito fue facilitar la comprensión de estas amenazas y reforzar la identificación de situaciones sospechosas, haciendo énfasis en la prevención y la protección de credenciales.

## Consideraciones de seguridad

- La demostración se realizó con fines educativos.
- Se utilizó un entorno virtual de práctica.
- No se realizaron pruebas sobre sistemas reales de la institución.
- La actividad se orientó a la concientización y prevención.
- No se publicarán credenciales, datos sensibles ni información que permita reproducir la demostración de manera insegura.

## Conclusión

El uso de un laboratorio virtual permitió acompañar los contenidos teóricos de la capacitación con una demostración práctica, favoreciendo la comprensión de los riesgos asociados al phishing y la importancia de adoptar medidas preventivas.
