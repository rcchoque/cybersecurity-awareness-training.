# Evidencias de evaluación

Esta carpeta contiene los archivos exportados de Google Forms utilizados como fuente de datos para el análisis de la capacitación en concientización sobre ciberseguridad.

## Archivos

- "diagnostico-inicial.xlsx": respuestas recopiladas antes de la capacitación, destinadas a identificar conocimientos previos y hábitos de seguridad informática.
- "evaluacion-final.xlsx": respuestas recopiladas al finalizar la capacitación, utilizadas para evaluar la comprensión de los temas abordados.

## Uso de los datos

Los datos fueron utilizados para realizar un análisis descriptivo de las respuestas, identificar conocimientos adquiridos y reconocer aspectos que podrían reforzarse en futuras instancias de capacitación.

Los resultados y las limitaciones del análisis se encuentran documentados en ""../../docs/results.md"" (../../docs/results.md).

## Privacidad

Los archivos deben compartirse únicamente en una versión que no exponga información personal, identificable ni sensible de los participantes.
